# Chat-It: Agent Guide & Activity Log

This file records architecture decisions, agent conventions, and a running log of changes made to the project. Every AI agent working on this codebase MUST review this file and update the **Activity Log** when making changes.

---

## Project Overview

- **Framework**: Next.js 16 (Turbopack, App Router, React 19)
- **Styling**: Tailwind CSS v4 (`@theme inline`), OKLCH semantic color tokens
- **Design System & Theme**: VTRON (tweakcn) with high-contrast STEM/math palette (royal blue primary `#2e67ff`, deep midnight navy `#0e142b`, obsidian dark mode)
- **UI System**: shadcn/ui with Base UI primitives (`base-sera` style)
- **Primary Typography**: IBM Plex Sans (self-hosted via `next/font/local`)
- **Icon Library**: `lucide-react`
- **Product Architecture**: Detailed in [`arch.md`](file:///d:/Programming/chat-it/arch.md)
- **Package Manager**: npm

## Agent Operational Rules

1. **Keep Next.js Agent Block Intact**: Never delete or alter the `<!-- BEGIN:nextjs-agent-rules -->` block generated by Next.js.
2. **Component Conventions**:
   - Use existing shadcn components in `components/ui/` rather than rolling custom markup.
   - For form layouts, use `FieldGroup` + `Field`.
   - Use semantic theme tokens (`bg-background`, `bg-primary`, `text-muted-foreground`), never raw Tailwind colors (e.g. `bg-blue-500`).
   - Use `cn()` from `@/lib/utils` or `cn` for class merging.

   - Always run `npm run lint` and `npm run typecheck` to confirm 0 errors.
